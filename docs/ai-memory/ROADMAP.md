# Roadmap

## Near Term

- Normalize known data inconsistencies such as the HackTricks URL split.
- Improve the README opening so the navigator promise is visible immediately.
- Review the most repeated resources for overuse or weak placement.
- Keep weekly memory maintenance and catalog audits lightweight and repeatable.

## Medium Term

- Expand structured resource coverage only when it materially improves navigator quality.
- Tighten broad paths so they remain anti-overwhelm and checkpoint-driven.
- Add carefully chosen high-signal hubs only when they fill a real gap.
- Keep durable memory current so future Codex sessions can bootstrap without loading long threads.

## Longer Term

- Consider limited automation for maintenance PRs, not direct main-branch edits.
- Consider light generation or synchronization helpers only if JSON/markdown drift becomes a recurring problem.
- Consider future website or richer UI work only after the GitHub-native catalog and memory system remain stable over time.

## Explicit Non-Goals For Now

- Uploaded resource archives or learning assets
- Broad automated ingestion of trending links
- Product/application features unrelated to cataloging, navigation, validation, or maintenance
