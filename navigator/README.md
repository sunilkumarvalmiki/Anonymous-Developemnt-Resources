# Resource Navigator

The Resource Navigator is the fast way to use this repository.

Instead of opening every category and collecting too many links, choose the path closest to your goal. Each path gives you the first resources, the next resources, what to skip for now, and a checkpoint that proves progress.

## How To Use a Path

1. Start with the first three resources only.
2. Finish the checkpoint before opening the deep dives.
3. Use the related category pages when you need more options.
4. Add better resources through [CONTRIBUTING.md](../CONTRIBUTING.md) when a path becomes outdated.

## Data

The structured source is in [data/resources.json](../data/resources.json) and [data/paths.json](../data/paths.json). Markdown pages are the readable layer; JSON data is the automation layer.
