# Become a Frontend Developer

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you want to build polished browser interfaces and understand modern frontend workflows.

## Outcome

You should finish with a deployable frontend project, solid web fundamentals, and enough framework knowledge to keep learning independently.

## First Three Resources

- [MDN Web Docs](https://developer.mozilla.org/) - Use this as the base reference for HTML, CSS, JavaScript, accessibility, and browser APIs.
- [The Modern JavaScript Tutorial](https://javascript.info/) - Use this to strengthen JavaScript before leaning too hard on frameworks.
- [Frontend Mentor](https://www.frontendmentor.io/) - Practice real UI implementation with responsive design challenges.

## Next Resources

- [React Docs](https://react.dev/) - Learn modern React directly from the official documentation.
- [TypeScript Docs](https://www.typescriptlang.org/docs/) - Add type safety after JavaScript fundamentals are stable.
- [Tailwind CSS Docs](https://tailwindcss.com/docs) - Learn a practical utility-first styling workflow.
- [web.dev](https://web.dev/) - Improve performance, accessibility, and web quality.
- [Developer Roadmaps](https://roadmap.sh/) - Check role expectations without turning the path into a checklist race.

## Deep Dives

- [Next.js Docs](https://nextjs.org/docs) - Move into full-stack React, routing, caching, and deployment patterns.
- [Vue Docs](https://vuejs.org/) - Compare another mainstream frontend framework.
- [Awesome Design Systems](https://github.com/alexpate/awesome-design-systems) - Study public design systems and component documentation.
- [Figma Community](https://www.figma.com/community) - Find design examples, UI kits, and prototyping references.

## Skip Until Later

- Memorizing every framework API.
- Advanced animation, micro-frontends, and build-system optimization before layout and JavaScript fundamentals are reliable.

## Practice Checkpoint

Build a responsive dashboard from a design, pass basic accessibility checks, and deploy it with a short case-study README.
