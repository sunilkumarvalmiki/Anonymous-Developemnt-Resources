# Find Tools for a New Project

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path when you have a project idea and need practical resources for APIs, hosting, deployment, automation, and supporting tools.

## Outcome

You should finish with a small stack decision note and a project setup that stays simple enough to maintain.

## First Three Resources

- [free-for.dev](https://github.com/ripienaar/free-for-dev) - Compare free tiers for hosting, databases, observability, email, and developer services.
- [Public APIs](https://github.com/public-apis/public-apis) - Find APIs that can power prototypes, demos, and learning projects.
- [GitHub Pages](https://pages.github.com/) - Publish simple static project pages and documentation quickly.

## Next Resources

- [Vercel Docs](https://vercel.com/docs) - Deploy frontend and full-stack apps with preview workflows.
- [Netlify Docs](https://docs.netlify.com/) - Compare deployment, forms, functions, and static hosting options.
- [Cloudflare Pages Docs](https://developers.cloudflare.com/pages/) - Explore edge-oriented deployment for web projects.
- [Awesome CLI Apps](https://github.com/agarrharr/awesome-cli-apps) - Find useful command-line tools for development and productivity.
- [GitHub Actions Docs](https://docs.github.com/en/actions) - Add automated validation and scheduled maintenance workflows.

## Deep Dives

- [Docker Docs](https://docs.docker.com/) - Containerize dependencies when local setup becomes fragile.
- [Terraform Registry](https://registry.terraform.io/) - Explore infrastructure providers and reusable modules.
- [OpenTelemetry Docs](https://opentelemetry.io/docs/) - Add observability when the project has operational signals to track.
- [Figma Community](https://www.figma.com/community) - Find interface templates and design references for product polish.

## Skip Until Later

- Adding tools only because they are popular.
- Paid infrastructure before free-tier limits, cleanup steps, and exit paths are clear.

## Practice Checkpoint

Create a one-page project stack note that lists the chosen API, hosting path, CI check, deployment target, and why each was selected.
