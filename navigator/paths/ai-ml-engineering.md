# Learn AI/ML Engineering

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you want practical AI and machine learning skills without starting from research papers first.

## Outcome

You should finish with a small data or model project that documents inputs, outputs, evaluation limits, and next improvements.

## First Three Resources

- [Python Docs](https://docs.python.org/3/) - Use the official language documentation as your base reference.
- [Kaggle Learn](https://www.kaggle.com/learn) - Start with short practical courses for Python, pandas, SQL, and machine learning.
- [Hugging Face Models](https://huggingface.co/models) - Discover models by task and understand what is already available.

## Next Resources

- [Hugging Face Datasets](https://huggingface.co/datasets) - Find datasets for experiments, evaluation, and prototypes.
- [Papers With Code](https://paperswithcode.com/) - Connect research papers with implementations, benchmarks, and datasets.
- [Machine Learning Tutorials](https://github.com/ujjwalkarn/Machine-Learning-Tutorials) - Explore community tutorials across common ML topics.
- [Public APIs](https://github.com/public-apis/public-apis) - Find APIs for model-powered applications and data projects.
- [Developer Roadmaps](https://roadmap.sh/) - Compare AI, data, backend, and software engineering skill expectations.

## Deep Dives

- [OSSU Computer Science](https://github.com/ossu/computer-science) - Use this for deeper math, algorithms, and CS foundations.
- [CS50x](https://cs50.harvard.edu/x/) - Fill programming and problem-solving gaps before deeper ML work.
- [freeCodeCamp](https://www.freecodecamp.org/) - Use project-based practice when you need more web or data basics.

## Skip Until Later

- Fine-tuning large models before understanding datasets, evaluation, and basic Python workflows.
- Using model demos without recording inputs, outputs, limitations, and evaluation notes.

## Practice Checkpoint

Create a small notebook or app that loads a dataset, runs a baseline model or hosted model, and documents evaluation limits.
