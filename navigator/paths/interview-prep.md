# Prepare for Developer Interviews

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you are preparing for developer interviews and need focus across practice, explanation, and project readiness.

## Outcome

You should finish with a repeatable interview study system, a project walkthrough, and a small set of reviewed practice problems.

## First Three Resources

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/) - Use this as the main interview preparation structure.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university) - Use this for deeper data structures and algorithms study.
- [LeetCode Problemset](https://leetcode.com/problemset/) - Practice tagged problems and review mistakes systematically.

## Next Resources

- [Frontend Interview Handbook](https://www.frontendinterviewhandbook.com/) - Add frontend-specific questions if you are applying for UI roles.
- [Awesome Interview Questions](https://github.com/DopplerHQ/awesome-interview-questions) - Find role-specific practice question collections.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) - Study system design patterns and tradeoffs.
- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) - Build deeper projects that create stronger interview stories.
- [Awesome README](https://github.com/matiassingers/awesome-readme) - Improve project explanations and portfolio documentation.

## Deep Dives

- [Developer Roadmaps](https://roadmap.sh/) - Check role expectations and missing topic areas.
- [freeCodeCamp](https://www.freecodecamp.org/) - Fill practical gaps through guided exercises and projects.

## Skip Until Later

- Random problem grinding without reviewing patterns and mistakes.
- Resume polish before you can explain one real project clearly.

## Practice Checkpoint

Prepare one project walkthrough, solve and review a small set of tagged problems, and write notes for tradeoffs you can explain aloud.
