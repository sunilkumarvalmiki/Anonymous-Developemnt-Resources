# Become a Backend Developer

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you want to build APIs, work with databases, and understand the server side of applications.

## Outcome

You should finish with a tested API, a relational database, a containerized local setup, and a simple architecture explanation.

## First Three Resources

- [Node.js Learn](https://nodejs.org/en/learn) - Start with backend JavaScript runtime fundamentals.
- [Express Docs](https://expressjs.com/) - Build simple API routes, middleware, and error handling.
- [PostgreSQL Docs](https://www.postgresql.org/docs/) - Learn relational database concepts from the official source.

## Next Resources

- [FastAPI Docs](https://fastapi.tiangolo.com/) - Compare a typed Python API framework.
- [Django Docs](https://docs.djangoproject.com/) - Study a batteries-included Python web framework.
- [Public APIs](https://github.com/public-apis/public-apis) - Find external APIs for practice projects.
- [Docker Docs](https://docs.docker.com/) - Containerize local backend dependencies and services.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) - Learn architecture vocabulary after you have built a simple service.

## Deep Dives

- [OpenTelemetry Docs](https://opentelemetry.io/docs/) - Learn tracing, metrics, and observability standards.
- [Prometheus Docs](https://prometheus.io/docs/) - Learn metrics, alerting, and monitoring concepts.
- [free-for.dev](https://github.com/ripienaar/free-for-dev) - Find low-cost services for experiments and deployments.

## Skip Until Later

- Distributed systems before you can build and test a simple API.
- Premature microservices before you understand one service, one database, and one deployment.

## Practice Checkpoint

Build a CRUD API with validation, tests, a PostgreSQL schema, Docker setup, and a short architecture note.
