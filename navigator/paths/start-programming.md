# Start Programming From Zero

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you are new to programming or returning after a long break.

## Outcome

You should finish with enough confidence to read simple code, edit a web page, use GitHub, and publish a small project.

## First Three Resources

- [freeCodeCamp](https://www.freecodecamp.org/) - Use the interactive lessons to build early repetition and confidence.
- [MDN Web Docs](https://developer.mozilla.org/) - Use this as the trustworthy reference for HTML, CSS, JavaScript, and browser behavior.
- [CS50x](https://cs50.harvard.edu/x/) - Use this for computer science foundations and problem-solving habits.

## Next Resources

- [The Odin Project](https://www.theodinproject.com/) - Follow this when you are ready for a complete project-based web curriculum.
- [The Modern JavaScript Tutorial](https://javascript.info/) - Use this to understand JavaScript more deeply after the first basics.
- [GitHub Skills](https://skills.github.com/) - Practice GitHub workflows in guided exercises.
- [Developer Roadmaps](https://roadmap.sh/) - Compare possible next directions without changing paths too early.
- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) - Pick one small rebuild project when basics start feeling comfortable.

## Deep Dives

- [OSSU Computer Science](https://github.com/ossu/computer-science) - Use this only when you want a long-term computer science curriculum.
- [Full Stack Open](https://fullstackopen.com/en/) - Use this after you can already build and explain small JavaScript projects.

## Skip Until Later

- Advanced system design, Kubernetes, and machine learning theory.
- Collecting dozens of courses before finishing one project-based path.

## Practice Checkpoint

Build and publish a small personal site with at least one interactive feature and a README explaining what you learned.
