# Learn DevOps and Cloud

[Back to Resource Navigator](../README.md)

## Who This Is For

Use this path if you already understand basic application development and want to automate, deploy, and observe software.

## Outcome

You should finish with a containerized application, automated validation, a deployment path, and a basic operations signal.

## First Three Resources

- [Docker Docs](https://docs.docker.com/) - Learn containers, Dockerfiles, Compose, images, and local service dependencies.
- [GitHub Actions Docs](https://docs.github.com/en/actions) - Automate validation, scheduled checks, builds, and deployment workflows.
- [free-for.dev](https://github.com/ripienaar/free-for-dev) - Find free tiers for safe experiments without committing to paid services.

## Next Resources

- [Kubernetes Docs](https://kubernetes.io/docs/home/) - Study orchestration after container basics are comfortable.
- [Terraform Registry](https://registry.terraform.io/) - Discover infrastructure providers and reusable modules.
- [Awesome Actions](https://github.com/sdras/awesome-actions) - Find reusable GitHub Actions and workflow patterns.
- [OpenTelemetry Docs](https://opentelemetry.io/docs/) - Learn metrics, traces, logs, and telemetry standards.
- [Prometheus Docs](https://prometheus.io/docs/) - Learn monitoring, PromQL, exporters, and alerting basics.

## Deep Dives

- [Awesome Docker](https://github.com/veggiemonk/awesome-docker) - Explore Docker tooling, examples, and ecosystem resources.
- [Cloudflare Pages Docs](https://developers.cloudflare.com/pages/) - Learn edge deployment for web projects.
- [Netlify Docs](https://docs.netlify.com/) - Compare static, function, and edge deployment workflows.

## Skip Until Later

- Multi-cluster Kubernetes operations.
- Cloud spending experiments before you understand free tiers, cleanup steps, and access controls.

## Practice Checkpoint

Containerize a small app, run tests in GitHub Actions, deploy it, and add one basic metric or health check.
