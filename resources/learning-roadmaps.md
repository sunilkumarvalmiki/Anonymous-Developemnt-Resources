# Learning and Roadmaps

Structured learning resources for developers who want a path, curriculum, or project sequence.

## Curricula and Roadmaps

- [Developer Roadmap](https://github.com/kamranahmedse/developer-roadmap) - Interactive roadmaps, guides, and learning paths for developer careers.
- [OSSU Computer Science](https://github.com/ossu/computer-science) - Free self-taught computer science curriculum using online courses.
- [Awesome Courses](https://github.com/prakhar1989/awesome-courses) - University-level computer science courses organized by topic.
- [Teach Yourself CS](https://teachyourselfcs.com/) - Opinionated computer science study guide for self-directed learners.
- [Open Source Society University Data Science](https://github.com/ossu/data-science) - Self-directed data science curriculum using online material.
- [Roadmap.sh](https://roadmap.sh/) - Visual developer roadmaps, skill guides, and checklists.
- [The Odin Project](https://www.theodinproject.com/) - Full-stack web development curriculum with projects and community support.
- [Full Stack Open](https://fullstackopen.com/en/) - University of Helsinki course for modern full-stack JavaScript development.
- [FreeCodeCamp](https://www.freecodecamp.org/learn/) - Free interactive coding curriculum with certifications.
- [CS50](https://cs50.harvard.edu/x/) - Harvard introduction to computer science and programming.

## Project-Based Learning

- [Build Your Own X](https://github.com/codecrafters-io/build-your-own-x) - Tutorials for recreating real-world technologies from scratch.
- [Project Based Learning](https://github.com/practical-tutorials/project-based-learning) - Programming tutorials organized around concrete projects.
- [App Ideas](https://github.com/florinpop17/app-ideas) - Application ideas for practicing frontend, backend, and full-stack skills.
- [RealWorld](https://github.com/gothinkster/realworld) - Full-stack example apps implementing the same Medium-style product across stacks.
- [30 Seconds of Code](https://github.com/Chalarangelo/30-seconds-of-code) - Short coding articles and snippets for practical development skills.
- [Frontend Mentor](https://www.frontendmentor.io/) - Realistic frontend challenges using professional designs.
- [Exercism](https://exercism.org/) - Programming exercises with mentoring and language tracks.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university) - Computer science and interview preparation study plan.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) - System design learning guide with examples and interview material.
- [Awesome Scalability](https://github.com/binhnguyennus/awesome-scalability) - Patterns and resources for scalable, reliable, large-scale systems.

## Practice Platforms

- [LeetCode](https://leetcode.com/) - Algorithm, data structure, and interview practice problems.
- [HackerRank](https://www.hackerrank.com/) - Programming challenges, interview practice, and skill assessments.
- [Codewars](https://www.codewars.com/) - Kata-based coding practice across many languages.
- [Advent of Code](https://adventofcode.com/) - Annual programming puzzles useful for practice and language learning.
- [Project Euler](https://projecteuler.net/) - Mathematical programming challenges.
- [Kaggle Learn](https://www.kaggle.com/learn) - Free micro-courses for data science and machine learning.
