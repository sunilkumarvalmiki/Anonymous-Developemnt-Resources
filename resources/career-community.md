# Career and Community

Interview preparation, career resources, contribution paths, student material, communities, and professional growth.

## Interview Preparation

- [Awesome Interview Questions](https://github.com/DopplerHQ/awesome-interview-questions) - Curated list of interview question lists across languages and technologies.
- [Coding Interview University](https://github.com/jwasham/coding-interview-university) - Study plan for software engineering interviews and computer science review.
- [System Design Primer](https://github.com/donnemartin/system-design-primer) - System design topics, examples, and interview preparation.
- [Tech Interview Handbook](https://github.com/yangshun/tech-interview-handbook) - Practical coding interview guidance, checklists, and preparation paths.
- [Front End Interview Handbook](https://github.com/yangshun/front-end-interview-handbook) - Frontend interview questions, concepts, and preparation material.
- [JavaScript Questions](https://github.com/lydiahallie/javascript-questions) - JavaScript interview and concept questions with explanations.
- [Awesome Scalability](https://github.com/binhnguyennus/awesome-scalability) - Scalable systems reading list useful for senior engineering interviews.
- [Hiring Without Whiteboards](https://github.com/poteto/hiring-without-whiteboards) - Companies with practical or non-whiteboard interview processes.

## Students and Open Source

- [A to Z Resources for Students](https://github.com/dipakkr/A-to-Z-Resources-for-Students) - Student-friendly development, design, hackathon, and learning resources.
- [Awesome for Beginners](https://github.com/MunGell/awesome-for-beginners) - Beginner-friendly open source projects.
- [First Contributions](https://github.com/firstcontributions/first-contributions) - Step-by-step guide for making a first open source contribution.
- [Up For Grabs](https://up-for-grabs.net/) - Projects with beginner-friendly issues.
- [Good First Issue](https://goodfirstissue.dev/) - Searchable good-first-issue finder.
- [GitHub Skills](https://skills.github.com/) - Interactive GitHub learning courses.
- [Open Source Guides](https://opensource.guide/) - Guides for launching, contributing to, and maintaining open source projects.
- [GitHub India](https://github.com/github/india) - GitHub resources and information for the developer community in India.
