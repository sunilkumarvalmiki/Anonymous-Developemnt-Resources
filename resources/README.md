# Resource Catalog Index

Use these pages to browse and maintain the catalog by intent. The main README stays short so the repository remains easy to scan.

## Categories

- [Mega Indexes](mega-indexes.md) - Source-of-sources indexes that unlock very large resource collections.
- [Learning and Roadmaps](learning-roadmaps.md) - Structured learning paths, curricula, roadmaps, and project-based practice.
- [Books, Courses, APIs, and Data](apis-data.md) - Free learning material, public APIs, datasets, and reusable data sources.
- [Tools and Services](tools-services.md) - Developer tools, hosting, cloud tiers, CI/CD, testing, observability, and productivity.
- [Languages and Frameworks](languages-frameworks.md) - Resource collections for languages, frameworks, runtimes, and platforms.
- [Design and Media](design-media.md) - Design systems, UI/UX inspiration, fonts, icons, stock media, and creative coding.
- [Security](security.md) - Ethical hacking, defensive security, OSINT, appsec, privacy, and secure engineering.
- [Career and Community](career-community.md) - Interview preparation, student resources, open source contribution, and communities.

## Maintenance Model

- Keep high-volume directories in [Mega Indexes](mega-indexes.md).
- Put direct category resources in the most specific category page.
- Use pull requests for additions so automation can catch duplicates, empty descriptions, and local-file mistakes.
