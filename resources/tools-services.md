# Tools and Services

Developer tools, services, automation, hosting, CI/CD, observability, and productivity resources.

## Free Tiers and Hosting

- [free-for.dev](https://github.com/ripienaar/free-for-dev) - Free-tier catalog for SaaS, PaaS, IaaS, APIs, developer tools, hosting, and infrastructure.
- [GitHub Pages](https://pages.github.com/) - Static site hosting directly from GitHub repositories.
- [Netlify](https://www.netlify.com/) - Static hosting, serverless functions, previews, and deployment workflows.
- [Vercel](https://vercel.com/) - Frontend cloud platform for static sites, Next.js, serverless functions, and previews.
- [Cloudflare Pages](https://pages.cloudflare.com/) - Static and full-stack deployment platform on Cloudflare's network.
- [Fly.io](https://fly.io/) - Application hosting near users with global regions and container support.
- [Railway](https://railway.app/) - Developer-friendly app, database, and service deployment platform.
- [Render](https://render.com/) - Cloud hosting for web services, static sites, cron jobs, workers, and databases.
- [Supabase](https://supabase.com/) - Postgres, auth, storage, realtime, edge functions, and backend services.
- [Firebase](https://firebase.google.com/) - App development platform for hosting, auth, databases, storage, functions, and analytics.
