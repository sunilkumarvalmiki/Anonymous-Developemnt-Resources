# Books, Courses, APIs, and Data

Free learning material, public APIs, datasets, and reusable data sources for development projects.

## Books and Courses

- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books) - Free programming books, courses, problem sets, podcasts, and learning resources in many languages.
- [GoBooks](https://github.com/dariubs/GoBooks) - Curated list of Go programming books.
- [Mind Expanding Books](https://github.com/hackerkid/Mind-Expanding-Books) - Broad reading list covering computer science, startups, history, psychology, and more.
- [JavaScript Must Watch](https://github.com/bolshchikov/js-must-watch) - Must-watch JavaScript talks and videos.
- [Machine Learning Tutorials](https://github.com/ujjwalkarn/Machine-Learning-Tutorials) - Machine learning and deep learning tutorials and articles.
- [Deep Learning Roadmap](https://github.com/astorfi/Deep-Learning-Roadmap) - Organized resources for deep learning researchers and developers.
- [Awesome Deep Learning](https://github.com/ChristosChristofidis/awesome-deep-learning) - Deep learning tutorials, projects, papers, and communities.
- [Awesome NLP](https://github.com/keon/awesome-nlp) - Natural language processing libraries, datasets, courses, and research resources.
- [Awesome Math](https://github.com/rossant/awesome-math) - Mathematics resources useful for computing and scientific work.
- [OpenStax](https://openstax.org/subjects) - Free peer-reviewed textbooks across math, science, and computing-adjacent subjects.

## Public APIs

- [Public APIs](https://github.com/public-apis/public-apis) - Public API list grouped by category, auth type, HTTPS support, and CORS status.
- [Public API Lists](https://github.com/public-api-lists/public-api-lists) - Searchable public API directory with JSON API support.
- [APIs.guru OpenAPI Directory](https://github.com/APIs-guru/openapi-directory) - Large directory of OpenAPI descriptions for public APIs.
- [RapidAPI Hub](https://rapidapi.com/hub) - API marketplace and discovery hub with many free and freemium APIs.
- [NASA APIs](https://api.nasa.gov/) - Official NASA APIs for imagery, space data, and science datasets.
- [Open Library APIs](https://openlibrary.org/developers/api) - APIs for books, covers, authors, and reading data.
- [The Cat API](https://thecatapi.com/) - Free image API useful for examples and prototypes.
- [REST Countries](https://restcountries.com/) - Country data API useful for demos, forms, and geography projects.
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) - Fake REST API for prototyping and tutorials.
- [Reqres](https://reqres.in/) - Hosted REST API for testing front-end and HTTP client behavior.

## Datasets and Data Portals

- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets) - Public datasets grouped by topic and domain.
- [Kaggle Datasets](https://www.kaggle.com/datasets) - Community datasets for data science, analysis, and machine learning practice.
- [Google Dataset Search](https://datasetsearch.research.google.com/) - Search engine for datasets across the web.
- [Data.gov](https://data.gov/) - United States government open data portal.
- [World Bank Open Data](https://data.worldbank.org/) - Global development indicators and datasets.
- [Our World in Data](https://ourworldindata.org/) - Research-backed datasets and visualizations on global issues.
- [UCI Machine Learning Repository](https://archive.ics.uci.edu/) - Classic machine learning datasets.
- [Hugging Face Datasets](https://huggingface.co/datasets) - Dataset hub for machine learning, NLP, vision, audio, and multimodal work.
