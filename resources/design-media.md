# Design and Media

Design systems, UI/UX references, stock assets, icon libraries, fonts, and creative coding resources.

## Design Systems and UI

- [Awesome Design Systems](https://github.com/alexpate/awesome-design-systems) - Design systems, pattern libraries, and UI guidelines.
- [Awesome Design Tools](https://github.com/goabstract/Awesome-Design-Tools) - Design tools and plugins for product, brand, and interface work.
- [Awesome Shadcn UI](https://github.com/birobirobiro/awesome-shadcn-ui) - shadcn/ui components, templates, registries, and tools.
- [Awesome Design Tokens](https://github.com/sturobson/Awesome-Design-Tokens) - Design token resources, tools, examples, and articles.
- [Figma Community](https://www.figma.com/community) - Community design files, templates, plugins, and UI kits.
- [Design Systems Repo](https://designsystemsrepo.com/) - Design systems, style guides, and design resources.
- [Mobbin](https://mobbin.com/) - Mobile and web UI reference library for product design research.
- [Page Flows](https://pageflows.com/) - User flow examples from real products.
- [UI Sources](https://www.uisources.com/) - Mobile app design patterns and flow references.
- [GoodUI](https://goodui.org/) - A/B-tested UI patterns and product design ideas.

## Assets, Fonts, and Icons

- [Awesome Stock Resources](https://github.com/neutraltone/awesome-stock-resources) - Free stock photography, video, illustrations, icons, fonts, and media resources.
- [Google Fonts](https://fonts.google.com/) - Open source font library for web and app design.
- [Fontsource](https://fontsource.org/) - Self-hostable open source fonts packaged for modern development.
- [Iconify](https://iconify.design/) - Unified icon framework with many open source icon sets.
- [Lucide](https://lucide.dev/) - Consistent open source icon set for interfaces.
- [Heroicons](https://heroicons.com/) - Open source SVG icons from the Tailwind CSS team.
- [Tabler Icons](https://tabler.io/icons) - Large open source icon set for web interfaces.
- [Simple Icons](https://simpleicons.org/) - SVG icons for popular brands.
- [unDraw](https://undraw.co/illustrations) - Open source illustrations for products and content.
- [Open Doodles](https://www.opendoodles.com/) - Free hand-drawn illustration library.

## Creative Coding and Media

- [Awesome Creative Coding](https://github.com/terkelg/awesome-creative-coding) - Creative coding, generative art, visualization, shaders, and WebGL resources.
- [MagicTools](https://github.com/ellisonleao/magictools) - Game development, art, audio, and design resources.
- [Awesome WebGL](https://github.com/sjfricke/awesome-webgl) - WebGL libraries, frameworks, demos, and learning resources.
- [The Book of Shaders](https://thebookofshaders.com/) - Shader programming guide and examples.
- [Pexels](https://www.pexels.com/) - Free stock photos and videos.
- [Pixabay](https://pixabay.com/) - Free images, videos, music, and sound effects.
- [Unsplash](https://unsplash.com/) - Free high-resolution photos.
- [Mixkit](https://mixkit.co/) - Free videos, music, sound effects, and templates.
