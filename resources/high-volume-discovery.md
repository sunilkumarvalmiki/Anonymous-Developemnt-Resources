# High-Volume Discovery Sources

This page is for scale. It links to live indexes, registries, topic searches, and catalogs that expose thousands to hundreds of thousands of downstream development resources without copying every item into this repository.

## Scale Evidence

- Ecosyste.ms Awesome exposes project counts for indexed lists, including examples such as public APIs with more than 1,400 downstream projects, self-hosted software with more than 1,300 projects, Go resources with more than 2,900 projects, and Python resources with more than 500 projects.
- Open Awesome categories show broad coverage across frontend, backend, platforms, programming languages, security, testing, data, books, editors, DevOps, and miscellaneous resource areas.
- Package registries such as npm, PyPI, Maven Central, NuGet, Docker Hub, Artifact Hub, Terraform Registry, and Visual Studio Marketplace each expose large live catalogs that can reach thousands to millions of developer resources.
- GitHub topic searches provide continuously updated discovery pages for developer tools, learning resources, APIs, AI, DevOps, security, system design, and open source contribution opportunities.
