# Security

Ethical, defensive, and educational security resources. Do not add piracy, malware distribution, credential theft, or unauthorized exploitation resources.

## Defensive and Application Security

- [Awesome Security](https://github.com/sbilly/awesome-security) - Security software, libraries, documents, books, and resources.
- [Awesome AppSec](https://github.com/paragonie/awesome-appsec) - Application security resources and secure development references.
- [Awesome Web Security](https://github.com/qazbnm456/awesome-web-security) - Web security materials, tools, and learning resources.
- [OWASP Cheat Sheet Series](https://github.com/OWASP/CheatSheetSeries) - Secure coding and application security cheat sheets.
- [OWASP Web Security Testing Guide](https://github.com/OWASP/wstg) - Web application security testing methodology and documentation.
- [OWASP Top 10](https://owasp.org/www-project-top-ten/) - Common web application security risks and guidance.
- [Security Headers](https://securityheaders.com/) - HTTP security header scanner and reference.
- [Mozilla Web Security Guidelines](https://infosec.mozilla.org/guidelines/web_security) - Practical web security guidance.
- [Awesome Threat Detection](https://github.com/0x4D31/awesome-threat-detection) - Threat detection and hunting resources.
- [Awesome Incident Response](https://github.com/meirwah/awesome-incident-response) - Incident response tools, references, and training material.

## Ethical Hacking and Research

- [Awesome Hacking](https://github.com/Hack-with-Github/Awesome-Hacking) - Educational hacking and security learning resources.
- [Awesome Pentest](https://github.com/enaqx/awesome-pentest) - Penetration testing resources, tools, and references.
- [Awesome Bug Bounty](https://github.com/djadmin/awesome-bug-bounty) - Bug bounty resources, platforms, methodologies, and reports.
- [The Art of Hacking](https://github.com/The-Art-of-Hacking/h4cker) - Ethical hacking, bug bounty, DFIR, AI security, and vulnerability research resources.
- [Awesome CTF](https://github.com/apsdehal/awesome-ctf) - Capture-the-flag frameworks, platforms, tools, and learning material.
- [Awesome Reverse Engineering](https://github.com/tylerha97/awesome-reversing) - Reverse engineering resources, tools, books, and references.
- [Awesome Malware Analysis](https://github.com/rshipp/awesome-malware-analysis) - Malware analysis tools and research references for controlled defensive environments.
- [Awesome OSINT](https://github.com/jivoi/awesome-osint) - Open-source intelligence resources and investigation tools.
- [PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings) - Security testing payloads and methodology references for authorized testing.
- [HackTricks](https://book.hacktricks.xyz/) - Security methodology notes for authorized labs, CTFs, and assessments.
