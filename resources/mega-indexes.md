# Mega Indexes

These are high-volume resource hubs and source-of-sources indexes. They are the fastest path to thousands of development resources without copying every downstream link into this repository.

## General Mega Hubs

- [sindresorhus/awesome](https://github.com/sindresorhus/awesome) - Canonical curated list of awesome lists across programming, platforms, tools, security, learning, and more.
- [Open Awesome](https://open-awesome.com/) - Searchable directory of awesome-list projects with category browsing and popularity signals.
- [AwesomeIndex](https://awesomeindex.dev/) - Discovery index for high-star resource repositories and curated technical collections.
- [0ex/more-awesome](https://github.com/0ex/more-awesome) - Extensive meta-list of awesome lists for discovering more topic-specific collections.
- [bayandin/awesome-awesomeness](https://github.com/bayandin/awesome-awesomeness) - Meta-list of awesome lists organized by topic.
- [mfornos/awesome-microservices](https://github.com/mfornos/awesome-microservices) - Curated resources for microservice architecture, tools, and patterns.
- [trimstray/the-book-of-secret-knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) - Large collection of manuals, cheat sheets, command-line tips, security references, and web tools.
- [codecrafters-io/build-your-own-x](https://github.com/codecrafters-io/build-your-own-x) - Project-based list for learning by recreating databases, shells, containers, search engines, and other systems.
- [EbookFoundation/free-programming-books](https://github.com/EbookFoundation/free-programming-books) - Massive collection of free books, courses, problem sets, podcasts, and programming resources.
- [public-apis/public-apis](https://github.com/public-apis/public-apis) - Large public API directory for experiments, demos, and integrations.
- [ripienaar/free-for-dev](https://github.com/ripienaar/free-for-dev) - Free-tier SaaS, PaaS, IaaS, and developer service catalog.
- [kamranahmedse/developer-roadmap](https://github.com/kamranahmedse/developer-roadmap) - Roadmaps, guides, and career learning paths for developers.
- [ossu/computer-science](https://github.com/ossu/computer-science) - Free self-taught computer science curriculum using online materials.
- [prakhar1989/awesome-courses](https://github.com/prakhar1989/awesome-courses) - University-level computer science courses and lectures.
- [MunGell/awesome-for-beginners](https://github.com/MunGell/awesome-for-beginners) - Beginner-friendly open source projects for first contributions.
