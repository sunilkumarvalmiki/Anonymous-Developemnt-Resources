# Security Policy

This repository contains resource links and maintenance automation, not application code. Security reports should focus on unsafe links, malicious resources, leaked secrets, or risky repository configuration.

## Reportable Issues

- A resource points to malware, phishing, credential theft, piracy, or unsafe downloads.
- A link has been hijacked or now redirects to unrelated or dangerous content.
- A workflow, script, or repository file exposes a secret or unsafe behavior.
- A security resource encourages unauthorized harm rather than ethical or defensive learning.

## How to Report

Open a GitHub issue with the affected URL, category file, and reason it should be removed or reviewed. If the issue involves a private secret, use GitHub's private vulnerability reporting if it is enabled for the repository.

## Maintenance Response

Unsafe links should be removed quickly. Questionable links can be moved to review until a maintainer confirms the resource is safe and on-scope.
